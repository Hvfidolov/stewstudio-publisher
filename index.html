Crankcase Files Publisher

A small internal tool that uploads finished Crankcase Files episodes from the Stew Studio production machine to the studio's own TikTok account.

What Crankcase Files is

Crankcase Files is a short-form video series that explains how car and engine systems work — turbochargers, differentials, ABS, CVT transmissions, engine cooling. Each episode is a vertical video built from procedurally generated 3D animation, narrated and rendered in-house.

What this tool does

Finished episodes are rendered on a local workstation as MP4 files. Rather than copying each file to a phone by hand, this tool uploads the finished file directly from the workstation to the studio's TikTok account, together with its title and description.

  1. The studio operator signs in to TikTok and grants the tool access to their own account.
  2. The operator selects a finished episode file on the workstation.
  3. The tool uploads the video to TikTok and reports the upload status.
  4. The operator reviews the post and publishes it.

How each permission is used

user.info.basic
Reads the open ID and display name of the signed-in account, so the tool can confirm which account an episode is about to be uploaded to before it starts. No profile data is stored beyond the current session.
video.upload
Uploads a finished episode to the account holder's TikTok drafts. The operator then opens the draft in the TikTok app, reviews it, and publishes it themselves. Nothing is made public by the tool.
video.publish
Posts a finished episode directly to the account holder's own profile, with the title and description entered by the operator on the workstation. Used only for episodes the operator has already reviewed locally, and only on the studio's own account.

Who can use it

This is not a public product. It runs on Stew Studio's own machine and is used only by the studio to post its own original videos to its own TikTok account. It is not distributed, has no sign-up, and does not post on behalf of anyone else.
