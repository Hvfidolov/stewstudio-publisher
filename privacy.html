Privacy Policy

Last updated: 15 November 2026

This policy covers the Crankcase Files Publisher ("the tool"), an internal application used by Stew Studio to upload its own finished videos to its own TikTok account.

Summary

The tool runs entirely on a single private workstation. It has no server, no database, no user accounts and no analytics. It does not collect data from anyone other than the studio operator who runs it, and it does not transmit data to anyone except TikTok.

What the tool stores

DataWhyWhere it is kept
TikTok access token and refresh token To stay signed in to the studio's own TikTok account between uploads, so the operator does not re-authorise for every episode. A file in the operator's own Windows user profile, on the local workstation only.
TikTok open ID and display name To show which account an episode is about to be uploaded to, as a confirmation step before upload. The same local file.
Upload records (file name, publish ID, status, timestamp) To track whether an upload succeeded and to avoid uploading the same episode twice. A local log file on the workstation.

The video files themselves are produced by Stew Studio and already exist on the workstation. They are sent to TikTok when the operator chooses to upload one.

What the tool does not do

  • It does not collect data from members of the public, viewers, or any TikTok user other than the studio's own account.
  • It does not sell, share, rent or disclose any data to third parties.
  • It does not use advertising networks, trackers, cookies or analytics services.
  • It does not read other people's TikTok content, followers, comments or messages.
  • It does not run in the background or upload anything without the operator starting it.

Information shared with TikTok

When the operator uploads an episode, the video file and its title and description are sent to TikTok through TikTok's official Content Posting API. That transfer is governed by TikTok's own Privacy Policy. The tool sends nothing to any other external service.

Retention and deletion

Tokens are kept only while the tool is in use. Access can be withdrawn at any time, and doing so immediately stops the tool from being able to access the account:

  1. In the TikTok app, open Settings and privacy → Security and permissions → Manage app permissions and remove this app.
  2. On the workstation, delete the stored token file in the operator's user profile.

Deleting the token file removes every piece of account information the tool holds. There is no copy anywhere else, because there is no server.

Security

Tokens are stored in the operator's own Windows user profile, outside the project folder and outside any version control, and are readable only by that Windows user account. The application credentials (client key and client secret) are kept in a local environment file that is likewise excluded from version control. All communication with TikTok uses HTTPS.

Children

The tool is not directed at children. It is an internal production utility with a single operator and no public sign-up.

Changes

If the tool's behaviour changes, this page is updated and the date at the top changes with it.
